# App Heladería 

## Clonar el repositorio

## Abrir una terminal y ejecutar:

git clone https://github.com/MarianaM21/App-Heladeria1.git

## Abrir el proyecto en Android Studio

1. Abrir Android Studio
2. Seleccionar "Open"
3. Buscar la carpeta del proyecto descargado

## Compilar el proyecto

1. Esperar a que Gradle termine de cargar
2. Si hay errores, presionar "Sync Project with Gradle Files"

##  Ejecutar la aplicación

1. Conectar un celular o usar un emulador
2. Presionar el botón "Run"

##  Requisitos

* Android Studio instalado
* SDK de Android configurado
* Conexión a internet (para dependencias)
